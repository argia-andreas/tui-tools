One continuous opening menu

Keep the centered terminal card; make saved connections and both actions feel like one menu. Up/Down crosses the separator without Tab. This browser simulation does not connect, save or read files.

Q1 Approve the continuous-list direction?

Recommended: equal row heights, shared gutters and only one mint highlight. Keep the small square logo beside the title. No separate action cards, oversized action icons or invented connection status.

F1 One selection, predictable boundaries

  • Work files → Team assets → Release archive → New connection → Browse local files. Up reverses this route. Stop at either end; do not wrap.
  • Enter on a saved entry opens existing connection details, not an immediate connection. New connection opens existing guided setup. Browse local files and Esc open the local workspace; Ctrl+C quits.
  • Back from details or canceled setup restores the launching row and scroll position. j/k navigate only here, not inside editable fields.
  • With many entries, only saved rows scroll; both actions stay visible. Down from the last entry reaches New connection. Up from New returns to that last entry.
  • Loading and failure are distinct from an empty list. Both actions remain usable. A late discovery result must not steal selection after the user moves to an action.

R1 Use terminal space for choices

Single-line entries show a muted remote/root beside the name at 80 columns. At 60 columns, keep names and actions readable and omit the inline path. If long names truncate, Enter still opens existing full details. This deliberately favors visible choices over multi-line decorative icons.

Inspection findings and limits

cmd/lazyftp/picker.go has separate focus targets for the saved list, New connection and local browsing. Its Up/Down handling cannot cross from the list to those actions. Its large-terminal action icons occupy three rows each, while saved items use a different gutter and footprint. workspace.go maps chooser Esc to returning to files and routes activation to the existing details/setup/workspace flows.

The chooser contains bookmarks plus configured remotes, so the heading says “Saved & configured”, not “Saved” alone. Display data here is illustrative. Source theme colors come from Midnight in internal/theme/theme.go. Earlier approved boards 13–18 establish the centered card, small square logo and theme direction.

The generated comparison board is only visual exploration: numeric row labels, inconsistent icon gutters and glow are not part of the recommendation. This cell-aligned prototype and the product document take precedence. No Go application code has changed and this is not real-terminal validation.
